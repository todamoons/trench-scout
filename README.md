# Trench Scout

Fast safety checks, dev history and narrative reads for Solana memecoins, built for trading next to Axiom.

**Download:** grab the latest `Trench-Scout-Setup-x.x.x.exe` from [Releases](../../releases/latest). Installed copies update themselves automatically.

Trench Scout is read-only: it never connects to or asks for your wallet. Never connect a wallet to a coin's website.
